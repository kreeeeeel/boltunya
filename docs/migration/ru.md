# Миграция на Spring

Сохраняются Electron, статический интерфейс Next.js, переносимый EXE и профиль JSON/Markdown. Spring выбран для бэкенда; добавлять базу данных ради миграции не требуется.

## Текущий этап — генерация контрактов

- [x] Зафиксирована семантическая база: 59 путей, 73 операции, 78 исходных схем. Добавлены три недостающих operationId и теги по функциям. Тесты сравнивают раскрытые операции/модели, включая необязательные PATCH-поля, null, строковые ID, двоичные загрузки и схему сессии `tiho`.
- [x] Единый источник разделён внутри `backend/contract/api/schema`: восемь файлов операций, отдельные модели и enum. Вынесены 28 общих enum и две модели запросов с сохранением JSON-структур; в корне теперь 108 именованных схем.
- [x] Добавлены Gradle-модули серверного контракта, generated Kotlin WebClient, типизированной Kotlin-обёртки и полноценного TypeScript HTTP SDK. Одна сборка контракта в Gradle сохраняет именованные вложенные ссылки; генераторы читают её после проверки исходного дерева. Прямая генерация из отдельных файлов теряла типы в OpenAPI Generator 7.25.0, поэтому типизация bundle проверяется отдельно.
- [x] Generated-исходники, JS/d.ts и npm-архивы остаются в `build/`; удалён сохранённый в Git файл frontend-деклараций. Текущий `openapi-fetch` получает переходные типы из того же источника до согласованного переключения транспорта и контроллеров.
- [x] Локально прошли 415 Kotlin-тестов (11 опциональных live пропущены), семь тестов установленного TypeScript SDK, 153 UI unit, 38 Electron, 10 скриптовых и 107 браузерных сценариев. Изолированный Gradle-тест удалил устаревшие исходники и классы без clean. Проверены нативное окно/трей/автозапуск, восстановление обновлятора/перенос профиля и медиа.
- [x] Собран и запущен локальный `complie/Aigram.exe` 2.6.30. При реальном перезапуске сохранены авторизация Telegram, настройки и ручные заметки памяти. Версия SDK-архива совпадает, его хеш включён в файл контрольных сумм.

Публикация проверяется по исходному коммиту, успешному [Windows Actions](https://github.com/kreeeeeel/boltunya/actions/workflows/release.yml), хешам опубликованных EXE/SDK и реальному запуску скачанного EXE. Результат фиксируется в релизе и локальном `complie/VERIFICATION.md`; одна локальная сборка ещё не является публикацией.

Использование и совместимость: [API-клиенты](../api-client/ru.md). Kotlin SDK использует поддерживаемые генератором Jackson 2 WebClient-кодеки на Spring 7; серверный generated API — Boot 4/Jackson 3.
