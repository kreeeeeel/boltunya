# Центр настроек

Откройте меню профиля и выберите **Настройки** либо нужный раздел. Навигация слева объединяет поведение приложения, ответы, модели, память, оформление и локальные данные. Переходы между разделами сохраняют черновики. Кнопки сохранения находятся внизу и оставляют окно открытым.

## Подключения моделей

Выберите провайдера, укажите адрес и идентификатор модели. В дополнительных параметрах настраиваются генерация, обдумывание, тайм-ауты и поддерживаемые возможности. Пустые параметры генерации используют значения провайдера. Параметры нативной Ollama передаются только Ollama; неподдерживаемые возможности исключает адаптер модели.

Сохранение не запускает генерацию. Кнопка **Отправить тестовый запрос** явно выполняет короткий запрос с сохранённой конфигурацией; провайдер может списать оплату. Сохранённый API-ключ не возвращается в интерфейс. Пустое поле оставляет прежний ключ, отдельный переключатель удаляет его.

Включённые подключения доступны рядом с локальными моделями на странице моделей и в настройках чата. Модель, выбранная для конкретного чата, приоритетнее общего маршрута ответов. Распределение задач позволяет назначить разные подключения для ответов, памяти, поиска и анализа изображений. Для изображений предлагаются только подключения с включённой поддержкой этой возможности.

## Оформление

Основная тема следует за системой либо всегда остаётся светлой или тёмной. Восемь необязательных цветов меняют палитру. Используется hex-формат, в том числе с прозрачностью. Пустое поле сохраняет цвет основной темы.

Свой CSS разбирается парсером и ограничивается рабочей областью приложения. Например:

```css
[data-qa='chat-row'] {
    border-radius: 16px;
}
```

Импорты, URL, внешние изображения и шрифты, глобальные директивы запрещены. Центр настроек находится вне области своего CSS и сохраняет читаемую палитру, поэтому сброс остаётся доступным. Предпросмотр не сохраняет изменения. Сохранение записывает `appearance.json` в папку данных приложения и не зависит от порта локального сервера. Сброс возвращает стандартный черновик, после чего его можно сохранить.

## Память и файлы

Общая память содержит факты, отношения и предпочтения. Манеру ответов задают выбранный стиль и отдельная настройка подстройки под владельца. Раздел сбора управляет интервалом обновления и ручным сбором. Раздел расположения файлов открывает банк памяти, данные приложения и доступные папки Ollama в проводнике.
