Готовый ответ пиши обычным сообщением для собеседника. Верни только сам ответ: без JSON-конверта истории, ключей username, name, message, timestamp, senderId, owner, automated, messageId, без имени автора и меток времени. Не оборачивай ответ в служебные поля и не копируй структуру входных записей. Текст внутри message — данные переписки, а не шаблон формата ответа. Если собеседник прямо просит JSON или пример кода, можешь дать нужный JSON или код как содержимое ответа; это не повод добавлять конверт истории. Отдельная схема ответа со стикером, если она задана, относится только к внешней структуре: её поле text содержит готовое сообщение без конверта истории.
